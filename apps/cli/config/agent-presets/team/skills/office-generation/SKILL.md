# Generate Office Documents

Compose the document programmatically, never by pasting plain text into an editor. Work in a scratch inside the user's workspace; keep the artifact beside where the user expects it.

## Choose a library

| Format | Library | Why |
| --- | --- | --- |
| Word `.docx` | `docx` (npm 9.x, MIT — https://github.com/dolanmiu/docx) | Full OOXML: headings, styles, tables, images, TOC |
| Excel `.xlsx` | `@sheetjs/xlsx` or `xlsx` (SheetJS, Apache-2.0 — https://github.com/SheetJS/sheetjs) | Multi-sheet workbooks, formulas, cell formats |
| PowerPoint `.pptx` | `pptxgenjs` (npm, MIT — https://github.com/gitbrent/PptxGenJS) | Slides with layouts, charts, speaker notes |
| PDF | `pdf-lib` (npm, MIT — https://github.com/Hopding/pdf-lib) | Layout-focused PDF generation in pure JS |

All four run offline, in-process, and are pure open source — no account, no network, no cloud conversion service.

## Install on demand

Run inside the user's workspace (their project), not the harness install:

```sh
pnpm add docx xlsx pptxgenjs pdf-lib
```

When pnpm is unavailable, `npm install ...` works equivalently.

## Generate a Word document

```sh
node --input-type=module -e "
import { Document, Packer, Paragraph, TextRun } from 'docx'
import fs from 'node:fs/promises'
const doc = new Document({ sections: [{ children: [
  new Paragraph({ heading: 'Heading1', children: [new TextRun('Report title')]}),
  new Paragraph({ children: [new TextRun('Body copy …')] }),
]}]})
const buf = await Packer.toBuffer(doc)
await fs.writeFile('report.docx', buf)
"
```

## Generate a workbook with two sheets

```sh
node --input-type=module -e "
import XLSX from 'xlsx'
const ws1 = XLSX.utils.json_to_sheet([{name:'alpha', qty:3}])
const ws2 = XLSX.utils.json_to_sheet([{sku:'X-1', count:4}])
const wb = XLSX.utils.book_new()
XLSX.utils.book_append_sheet(wb, ws1, 'orders')
XLSX.utils.book_append_sheet(wb, ws2, 'inventory')
XLSX.writeFile(wb, 'book.xlsx')
"
```

## Generate a deck

```sh
node --input-type=module -e "
import PptxGenJS from 'pptxgenjs'
const p = new PptxGenJS()
p.defineSlideMaster({ title: 'B', background: { color: 'FFFFFF' }, slideNumber: { x: 0.3, y: '90%' } })
const s1 = p.addSlide({ masterName: 'B' })
s1.addText('Title', { x: 0.5, y: 0.4, w: 9, h: 0.8, fontSize: 24, bold: true })
s1.addText('Bullet 1\nBullet 2', { x: 0.5, y: 1.4, w: 9, h: 2.4, fontSize: 16 })
await p.writeFile({ fileName: 'deck.pptx' })
"
```

## Generate a PDF

```sh
node --input-type=module -e "
import { PDFDocument, StandardFonts } from 'pdf-lib'
import fs from 'node:fs/promises'
const pdf = await PDFDocument.create()
const page = pdf.addPage([595, 842])
const font = await pdf.embedFont(StandardFonts.Helvetica)
page.drawText('Report generated by the agent', { x: 50, y: 780, size: 18, font })
await fs.writeFile('report.pdf', await pdf.save())
"
```

## Constraints

- For CJK (Chinese/Japanese/Korean) text in PDFs, register a TTF/OTF before rendering: `pdf.registerFontkit(fontkit)` and `embedFont(ttfBytes)` from `@pdfme/fontkit` — the standard 14 fonts are Latin-only.
- Asked-for formats win: do not convert a requested `.docx` into `.md` and call it a document.
- When the user supplies charts or images, embed via the library's image API (`addImage`, `media`), never by linking remote URLs.
- Verify the artifact exists and (when possible) re-parse it — open the `.xlsx` back with the same library to prove the values landed.
